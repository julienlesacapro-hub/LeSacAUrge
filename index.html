Mise en place de la synchronisation

  1. Créez un projet gratuit sur console.firebase.google.com.
  2. Menu Build puis Realtime Database : créer une base, région europe-west1 (Belgique).
  3. Onglet Règles : collez le contenu du fichier database.rules.json fourni avec l'application, puis publiez.
  4. Copiez l'adresse de la base (https://...firebasedatabase.app) dans le champ prévu, sur l'ordinateur.
  5. Sur l'ordinateur : Générer un code, puis Activer.
  6. Sur le téléphone : scannez le QR code affiché (ou saisissez l'adresse et le code), puis Activer.

Sans synchronisation, l'application fonctionne entièrement en local, hors ligne.
